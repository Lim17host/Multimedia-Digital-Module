A. Konsepto ng Suplay

Gabay na Video

Panoorin ang maikling video na ito bago talakayin ang mga konsepto at salik na nakaaapekto sa suplay:

Kahulugan ng Suplay

Ang suplay ay tumutukoy sa dami ng produkto at serbisyo na handa at kayang ipagbili ng mga prodyuser sa iba’t ibang presyo sa isang takdang panahon.

Ang Batas ng Suplay

Ayon sa Batas ng Suplay, kapag tumataas ang presyo, tumataas din ang dami ng produkto o serbisyo na handa at kayang ipagbili.

Ang ceteris paribus ay nangangahulugang kapag bumababa ang presyo, bumababa rin ang dami ng produkto o serbisyo na handa at kayang ipagbili.

Ipinapakita ng batas na ito na ang presyo ng produkto o serbisyo sa pamilihan ang pangunahing batayan ng prodyuser sa paglikha. Dahil dito, higit ang kanilang pagnanais na magbenta ng marami kapag mataas ang presyo.

Tatlong paraan upang maipakita ang Ugnayan ng Presyo at Suplay

Supply Schedule

Ang supply schedule ay isang talaan na nagpapakita ng dami ng kaya at gustong ipagbili ng mga prodyuser sa iba’t ibang presyo.

Ang iskedyul na makikita sa talahanayan ay tumutukoy sa quantity supplied para sa kendi sa iba’t ibang presyo. Halimbawa, sa halagang piso (Php 1.00) bawat piraso ng kendi, sampu (10) lamang ang dami ng handa at kayang ipagbili ng mga prodyuser. Malinaw na ipinapakita ang direktang ugnayan ng presyo at quantity supplied ng kendi para sa prodyuser.

Supply Curve

Ang supply curve ay isang grapikong paglalarawan ng ugnayan ng presyo at quantity supplied.

Ang graph sa itaas ay batay sa supply schedule na nasa talahanayan. Kung ilalapat sa graph ang iba’t ibang kumbinasyon ng mga presyo at quantity supplied ay mabubuo ang supply curve para dito. Halimbawa, sa Punto B presyo ng kendi sa piso, ang presyo ay piso (Php 1), sampu (10) ang dami ng kendi na gusto at handang ipagbili ng prodyuser; sa punto C na ang presyo ay dalawang piso (Php 2), dalawampu (20) ang dami ng kendi na gusto at handang ipagbili ng prodyuser. Kung tutuntunin ang mga puntong ito hanggang punto F ay makakabuo ng isang kurbang pataas o upward sloping curve. Ang kurbang ito ay nagpapakita ng direktang ugnayan sa pagitan ng presyo at sa dami ng gusto at handang ipagbili ng mga mamimili.

Supply Function

Ang supply function ay isa ring paraan ng pagpapakita ng ugnayan ng presyo at quantity supplied. Ito ay sa pamamagitan ng mathematical equation

1. Qs = f(P)

Kung saan:

Qs (quantity supplied) = ay tumatayong dependent Variable

P (presyo) = independent variable

2. Qs = c + bP

Kung saan:

Qs = dami ng suplay

P = presyo

c = intercept (bilang ng Qs kung ang presyo ay 0)

b = slope = ΔQs

Ngayon, suriin at pag-aralan natin ang kompyutasyon sa ibaba upang mapatunayan na ang relasyon ng datos ng supply schedule at ang supply function ay iisa. Gamitin ang supply function mula sa supply schedule para sa kendi, kompyutin ang Qs kung: Qs = 0 + 4P *(o Qs = 0 + 10P batay sa halimbawa)*

Kapag ang P = 1, Qs = ?

Qs = 0 + 10P
Qs = 0 + 10(1)
Qs = 0 + 10
Qs = 10 piraso

Kapag ang P = 5, Qs = ?

Qs = 0 + 10P
Qs = 0 + 10(5)
Qs = 0 + 50
Qs = 50 piraso

Gamit ang supply function ay makuha ang dami ng quantity supplied kung may ibinigay na presyo. I-substitute lamang ang presyo sa variable na P at i-multiply ito sa slope na +10 at idagdag ang intercept na 0.
